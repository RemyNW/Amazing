== 6. Glossaire des Métriques

=== Métriques de Qualité du Clustering

#### Silhouette Score
* **Plage** : [-1, 1]
* **Interprétation** : Mesure la cohésion intra-cluster vs séparation inter-cluster
* **Seuils** :
  - > 0.5 : Excellent clustering
  - 0.3-0.5 : Bon clustering
  - < 0.3 : Clustering faible
* **Calcul** : Moyenne des scores individuels de silhouette

#### Davies-Bouldin Index
* **Plage** : [0, +∞]
* **Interprétation** : Similarité moyenne entre clusters
* **Seuils** :
  - < 1.0 : Très bon clustering
  - 1.0-2.0 : Bon clustering
  - > 2.0 : Clustering faible
* **Principe** : Plus proche de 0 = meilleur

#### Calinski-Harabasz Score
* **Plage** : [0, +∞]
* **Interprétation** : Ratio variance inter-cluster / variance intra-cluster
* **Principe** : Plus élevé = meilleur
* **Note** : Pas de seuil absolu, comparaison relative

=== Métriques de Stabilité

#### Variance de Distribution
* **Calcul** : Variance des pourcentages de chaque cluster à travers les périodes
* **Seuils** :
  - < 1% : Très Stable
  - 1-5% : Stable
  - > 5% : Instable

#### Taux de Rétention
* **Calcul** : % d'utilisateurs restant dans le même cluster entre 2 périodes
* **Seuils** :
  - > 80% : Très Stable
  - 60-80% : Stable
  - < 60% : Instable

=== Paramètres d'Échantillonnage

#### Échantillonnage Stratifié pour Silhouette Score
* **Taille cible** : 50,000 utilisateurs
* **Méthode** : Échantillonnage proportionnel par cluster
* **Raison** : Optimisation computationnelle pour grandes données
* **Impact** : Représentatif de la population totale
